# RadarLab — Project Brief (single source of truth for all contributors/agents)

Owner: Enes Erdoğan (4th-year EEE, Abdullah Gül University). License: MIT.

## Goal
A **research-grade, open-source FMCW MIMO radar simulation framework** that:
1. Is physically faithful enough to be **validated against theory** (CRLB, analytic Pfa) and later against **real hardware data** (TI mmWave AWR/IWR + DCA1000 raw ADC captures).
2. Has an **interactive in-browser front-end** (GitHub Pages, no install) that shows the full signal chain step by step.
3. Can support a **publication** (target candidates: IEEE SIU 2027 conference paper, JOSS software paper, later a journal such as IEEE Access / SoftwareX).
4. Covers both **automotive (77 GHz)** and **counter-UAS / drone detection (24 GHz, micro-Doppler)** scenarios.

Why two implementations: Python is the reference for research/paper/real data; TypeScript runs at interactive frame rates in the browser (Pyodide CDN is not reachable from our build sandbox and is heavy). **Consistency is enforced by golden vectors** (`golden/`), which is itself a validation point for the paper.

## Binding conventions (both implementations MUST follow)
- c = 299792458 m/s. SI units everywhere internally (m, s, Hz, rad). UI may show km/h, deg, MHz/µs.
- Coordinates: radar at origin, boresight +y, x to the right, z up. Azimuth θ = atan2(x, y) (positive to the right). Elevation φ = atan2(z, hypot(x,y)).
- Radial velocity vr = d|p|/dt; **positive = receding** (moving away).
- Config fields (names identical in py/ts, camelCase in TS, snake_case in Python):
  fc, slope [Hz/s], fs [Hz], nSamples N, adcStartTime [s] (default 0), chirpPeriod Tc [s] (ramp+idle, per TX), nChirps M (per TX per frame), txPos / rxPos (element x-positions in wavelengths; optional z), framePeriod [s], iqMode 'complex' | 'real'.
  Derived: λ = c/fc; Te = nTx·Tc; B_eff = slope·N/fs; ΔR = c/(2·B_eff); Rmax = fs·c/(2·slope) (complex IF; half for real IF); Δv = λ/(2·M·Te); vmax = λ/(4·Te); virtual array: pos_k = txPos[t] + rxPos[r], k = t·nRx + r.
- TDM-MIMO timing: chirp start time of chirp m from TX t: t_{m,t} = m·Te + t·Tc. ADC sample n at t_{m,t} + adcStartTime + n/fs.
- Beat (IF) signal of one point scatterer, complex IQ, before noise/impairments:
  τ(t) = 2R(t)/c, with R(t) linear within a chirp: R(t) = R_m + vr_m·(t − t_{m,t}), where R_m, vr_m are the scatterer's instantaneous range/radial velocity at t_{m,t}.
  x[k,m,n] = A · exp( j·[ 2π( fc·τ + slope·τ·t_f − ½·slope·τ² ) + 2π·pos_k·sin θ·cos φ + φ0 ] ), t_f = adcStartTime + n/fs, τ evaluated at t_{m,t}+t_f.
  (The −½·slope·τ² residual-video-phase term is included. φ0 = scatterer phase; golden vectors use φ0 = 0.)
- Data cube layout: complex, shape (K virtual channels, M chirps, N samples), C-order. Range-Doppler cube: (K, N range bins, M Doppler bins), Doppler fftshifted so bin M/2 = 0 m/s.
- FFT sign: forward = exp(−j2πkn/N). Hence positive beat frequency → positive range bin; receding target → Doppler bin > M/2; target at θ>0 → positive angle bin after fftshift.
- Noise: complex white Gaussian, variance σ² = 1 per complex sample (σ²/2 per I and Q) in 'snr' amplitude mode.
- Amplitude modes:
  'snr': A = sqrt(σ_rcs) · (R_ref/R)² · 10^(snrRefDb/20) (snrRefDb = per-sample SNR of a 1 m² target at R_ref).
  'physical': radar equation Pr = Pt·Gt·Gr·λ²·σ / ((4π)³·R⁴·L), noise Pn = k·T0·F·fs (complex sampling); A = sqrt(Pr/Pn) with noise variance 1.
- Windows: periodic Hann default; coherent-gain normalization (divide by Σw) for range and Doppler FFTs.
- CFAR on square-law RD power map P[r,d] = Σ_k |X[k,r,d]|². Doppler axis circular, range axis clipped (use available cells; recompute α for the actual training-cell count). CA: α = N·(Pfa^(−1/N) − 1). OS: k = round(rank·N), solve Pfa = Π_{i=0}^{k−1} (N−i)/(N−i+α) by bisection. (Note: with K>1 non-coherent channels the noise is Gamma(K), not exponential; document this; analytic tests use K=1 or the Gamma-exact formula.)
- TDM Doppler-induced phase compensation before angle estimation: multiply TX-t channels by exp(−j·2π·(2v/λ)·t·Tc) using the estimated v (from fractional Doppler bin).
- Golden vector JSON schema (golden/*.json): `{ "name", "description", "config": {...camelCase}, "scatterers": [{ "x","y","z","vx","vy","vz","rcs","phase0" }], "amplitudeMode", "snrRefDb", "refRange", "noise": false, "cube": { "shape":[K,M,N], "re":[...], "im":[...] } (tiny configs only), "rdPowerDb": {...}, "expected": { "peaks":[{ "rangeBin","dopplerBin","angleBin","range","velocity","angleDeg" }] }, "tolerances": {...} }`. Generated only by `python/scripts/export_golden.py`.

## Fidelity roadmap (phased)
Phase 1 (core, now): point/extended targets, TDM-MIMO arbitrary array, exact beat model, noise, Hann, range/Doppler FFT, MTI, CA/OS/GO/SO-CFAR, clustering, FFT-DoA (+ MVDR/MUSIC in Python), EKF tracker (position + radial velocity), micro-Doppler STFT (drone/bird/pedestrian), golden vectors, unit tests vs analytic results.
Phase 2 (realism): Swerling 0/1/3, antenna element patterns, ADC quantization & clipping, IF HPF/LPF, phase noise (PLL model with range correlation), Tx→Rx leakage, IQ imbalance, chirp nonlinearity, two-ray ground multipath, distributed clutter, FMCW mutual interference.
Phase 3 (real-world): TI mmWave .cfg parser → config; DCA1000 .bin reader → cube; same chain on real data; compare sim vs real; browser upload of real captures.
Phase 4 (paper): Monte-Carlo validation (Pd/Pfa ROC vs theory, RMSE vs CRLB for range/velocity/angle), runtime benchmarks (py vs browser), micro-Doppler drone vs bird case study (+ simple classifier), paper draft.
